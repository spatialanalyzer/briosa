# SDK binding reference

This tree is a retained SpatialAnalyzer `2026.1.0529.7` evidence snapshot. It reconciles observed SDK method names with the committed interop surface and records reviewed semantic families.

The snapshot is not runtime registration, public protocol coverage, or proof that any MP command is implemented. Historical `protocol`, `worker`, `adapter`, `fake`, or `generator` coverage fields describe the retired evidence system and must not be used as current support claims. Current support is defined only by handwritten protobuf and operation source registered in `SpatialAnalyzerApi.Operations`.
