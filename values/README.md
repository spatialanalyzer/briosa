# Semantic value evidence

This tree retains curated exact-target and pinned ObjectiveSA-derived semantic evidence that may help implement future handwritten operations.

It is non-authoritative reference material. A recorded value, choice, sample, default candidate, or ObjectiveSA match does not create a public field, establish an omission default, approve an operation, or prove exact-target runtime behavior. Exact-target evidence wins over ObjectiveSA on conflict, and every public choice or default must be reviewed in the operation pull request.

The former value-evidence generator and completeness gates were retired in issue #132. See [ADR 0024](../docs/architecture/0024-handwritten-mp-operation-vertical-slices.md).
